# Research Program

**Version:** 0.1 — October 3, 2026  
**Status:** Initial program; narrow and revisable

## Primary question

> **What must a representation preserve for different questions to remain answerable as independent complexity increases?**

Separate variables that are often conflated: system size, constraint count, independent degrees of freedom, representation size, requested output, retained information, recovery cost, computation cost, and consequence/value. No exponential or monotonic relationship is assumed.

## Program A — Resolution Frontier

Hold the underlying system fixed and change the requested output: existence, one witness, optimum value, every optimizer, complete feasible set, then robustness under an added constraint.

For each transition identify the smallest currently known adequate representation and the first counterexample to any smaller candidate.

Target map:

> **question → sufficient representation → omitted information → failure trigger → recovery cost**

Do not assume these questions form a simple linear hierarchy.

## Program B — Independent Complexity

Hold the output roughly fixed while comparing more participants generated from the same low-rank structure, algebraically dependent constraints, and genuinely independent parameters.

Ask whether representational demand tracks participant count, independent rank, interaction order, arithmetic structure, or something else.

## Program C — Optionality Cost

Study what is lost when a representation is optimized for today's question.

Measure which future questions remain answerable, what source recovery is required, whether recovery is exact, and the cost of preserving more optionality up front.

Working question:

> **How much representation should be retained now when future questions are not fully known?**

## Program D — Adaptive Enrichment

Compare always-rich representation, always-compressed representation, and adaptive compression that enriches only after a concrete failure exposes missing consequential structure.

Correctness comes first. Efficiency claims require comparable cost data.

## Program E — Human-facing mediation

Later ask whether a large machine-facing representation can support a much smaller human-facing view without hiding distinctions that change the decision.

This connects to reversible compression but requires its own evidence. Do not infer cognitive benefit from mathematical adequacy.

## First laboratory

Use Lonely Runner first because it already contains frozen compact representations, exact failures, richer recoveries, a rank-three transition, multiple output obligations, and physical-time ground truth.

Do not rerun old experiments merely under a new label. First extract a few existing episodes into Representation Records. Then design one experiment whose independent variable is explicitly **representational demand**, not merely runner count.

## First milestone

Demonstrate at least one reproducible case where changing the requested question or independent structure changes the minimum known adequate representation because of a specific consequential distinction.

## Failure criterion

If Representation Science merely renames ordinary modeling practice without producing sharper questions, reusable records, falsifiable comparisons, or transferable methods, say so.

A new name is not a result.
