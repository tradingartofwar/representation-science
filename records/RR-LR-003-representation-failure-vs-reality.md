# RR-LR-003 — Representation failure is not underlying-system failure

**Date:** 2026-10-03  
**Laboratory:** Lonely Runner  
**Status:** OBSERVED finite obstruction with exact physical counterexample

## Underlying system / reality

The rank-three sheet-coverage program for the stationary-reference family generated from independent parameters p, q, r.

A supplied class of 36 sheets was used as candidate witness sources.

## Question

If every object in a chosen representation class fails to produce a witness, may we infer that no physical witness exists?

## Representation tested

The complete supplied 36-sheet source class used by the sheet-coverage experiment.

## Information retained

Each supplied sheet carried shared safety geometry plus integer-contact and physical-recovery information within its declared source class.

## Information omitted

Physical-safe structure not representable by any of those supplied sheets.

## Failure

At configuration

(p,q,r) = (1,2,40),

all 36 supplied sheets fail.

Nevertheless, the source analysis gives a valid physical 1/8-safe time:

t = 25/152.

Thus the source class is incomplete for the existence question at this configuration.

The later orbit-interval representation recovers the fixed-family obstruction, including the r=40k pattern, by retaining a different class of source objects.

## Consequential distinction

> **Failure of a representation class must remain distinct from failure of the represented reality.**

The statement “no supplied sheet yields a witness” is not equivalent to “no witness exists.”

## Enrichment that repairs the reached failure

Return to the physical safe core and preserve closed orbit intervals, isolated points, and clock lifts rather than restricting recovery to the supplied sheet class.

For the fixed (1,2,r) family, the subsequent interval construction provides a candidate using one fixed interval plus one isolated point.

## Adequacy claim

The 36-sheet class is inadequate as a uniform existence carrier for the tested larger family.

This record does not claim the orbit-interval representation is universally adequate for arbitrary rank-three Lonely Runner systems.

## Representation cost

The richer representation retains a broader set of continuous and isolated source components. Comparative storage and query complexity have not been reduced to a common metric.

## Future questions

Can a representation system detect that its own source class is exhausted and automatically reopen a richer source?

Can inadequacy certificates be made first-class outputs?
