# RR-LR-004 — Participant count and independent structure are different complexity variables

**Date:** 2026-10-03  
**Laboratory:** Lonely Runner  
**Status:** OBSERVED finite transfer result

## Underlying system / reality

Earlier structured tests added runners whose speeds were generated from the same two underlying parameters.

The September 30 experiment instead replaced one moving speed by a free parameter r, producing a genuinely rank-three coefficient family while retaining ten total runners.

## Question

Does a compact representation that works while participant count grows inside a two-parameter family transfer unchanged when one new independent degree of freedom is introduced?

## Representation tested

A frozen four-sheet menu selected from training data.

## Information retained

The selected sheets retained exact safety geometry, integer contact, and physical recovery for their source objects.

## Information omitted

Alternative supplied sheets outside the compact menu and richer three-dimensional structure not represented by the menu.

## Result

The compact four-sheet menu covered:

- 89/89 training configurations;
- 310/318 held-out configurations.

Eight held-out configurations failed the frozen menu.

Using all 36 supplied sheets covered all 407 tested configurations.

Separately structured physical-time checking validated the stored witnesses and confirmed every tested configuration had a physical 1/8 witness.

The menu was not repaired after seeing the held-out failures.

## Consequential distinctions exposed

The rank-three test revealed at least three separate information losses:

1. separate projection marginals can omit the common point;
2. unsaturated integer relations can admit false orbit components;
3. a canonical pair clock can discard valid physical lifts.

## Interpretation

The experiment does not show that “three dimensions are hard” in any universal sense.

It does show that adding genuinely independent structure is not equivalent to adding more participants generated from an existing low-rank family.

> **Constraint count and independent representational rank should be tracked separately.**

## Adequacy claim

The frozen compact menu was inadequate for uniform held-out coverage.

The full supplied sheet class was adequate on the tested 407-case domain.

No universal rank-three coverage theorem follows.

## Representation cost

The compact menu used 4 source sheets; the richer tested source class used 36. This is an object-count comparison only, not a general representation-complexity measure.

## Future questions

Which quantity best predicts representational demand:

- participant count;
- independent rank;
- interaction order;
- arithmetic structure;
- requested output;
- or some combination?

## Pre-execution audit clarification — 2026-10-03

The pinned source trained this four-sheet menu on rank-three configurations; it explicitly describes a dimensional adaptation of the compiler. This was not an unchanged rank-two menu applied directly to rank-three holdout data. The observed misses establish incomplete held-out coverage for that selected menu within rank three. They do not isolate the causal effect of increasing rank against a matched rank-two control.

Coefficient-family rank, participant count and fixed-instance orbit dimension remain separate variables. Every fixed integer-speed instance here has a one-dimensional periodic orbit. Whether increasing independent family rank forces a larger adequate representation remains **OPEN**. See the [EXP-001 audit](../experiments/EXP-001-pre-execution-audit-2026-10-03.md); historical counts and source status are unchanged.
