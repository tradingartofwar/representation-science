# Laboratory Two — Local Time Interpretation

Selected on 2026-10-03; [selection rationale and alternatives](../laboratory-two/SELECTION-2026-10-03.md).

Initial task: return every UTC interpretation of a minute-grid local label in `America/New_York` during 2024, relative to IANA tzdata `2025b`, including correct missing/unique/ambiguous status and completeness evidence.

The [qualified C1 packet](../laboratory-two/assessment-2026-10-03/C1-local-time.md) contains primary source pointers, source identities, the competent conventional baseline and exposed development inputs. The [transfer design](../laboratory-two/TRANSFER_DESIGN_v0.1.md) supplies the governing comparison and claim rules.

EXP-002 will test this bounded contract. Its executable freeze is being prepared; no transfer evaluation has run. Source-relative correctness is the initial target. User intention, future time-zone changes, independent-rank scaling and broad incremental usefulness remain outside this experiment.

IANA and the software projects remain the sources for their data and documented semantics. Representation Science owns the experimental contract, evidence trail and scoped interpretation, not those established methods.
