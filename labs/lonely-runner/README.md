# Laboratory One — Lonely Runner

## Why this laboratory

The Lonely Runner Conjecture provides a controlled environment for studying representation adequacy. The underlying motion is simple enough to check exactly while simultaneous compatibility becomes structurally rich.

It supports deliberate variation of runner count, independent parameter rank, requested output, threshold, representation type, compression level, and recovery obligation.

Most importantly, proposed representations can often be checked against exact physical-time ground truth.

## Candidate first records

**Marginal → joint compatibility.** Separate feasible projections can omit the requirement that constraints coexist at one point. Candidate consequential distinction: jointness.

**Positive-width intervals → isolated points.** A tested configuration has only isolated one-eighth-safe times. Candidate distinction: equality/zero-measure structure can be decisive for existence even when irrelevant to positive-width summaries.

**Compact sheets → richer sheets → orbit intervals.** A compact rank-three menu misses held-out cases; a richer supplied sheet class covers the finite domain; a later exact source-class obstruction leaves a valid physical witness outside that class; interval-plus-point recovery restores tested coverage. Candidate distinction: representation failure can be separated from physical nonexistence.

**Dependent participant growth → independent rank.** Adding runners within the same low-dimensional family differs from introducing a genuinely independent parameter.

## First new experiment

Do not simply add an eleventh runner.

Prefer a Resolution Frontier experiment on a fixed system: freeze one underlying configuration/source, then ask existence, one witness, optimum, every maximizer, and complete safe set. Determine which previously omitted information becomes necessary as the requested output changes.

The experiment should compare at least one conventional exact representation with any CC-derived representation used. CC is not privileged.
