# Memory / reconstruction observations

**Status:** exploratory field observations; not a cognitive model, diagnosis, or established memory mechanism.

This folder preserves bounded observations from guided recall sessions conducted during Representation Science work.

The aim is not to infer neural storage from introspection. The narrower research object is:

> Given a cue or present demand, what becomes consciously available, in what order, with what confidence, and what changes when the reconstruction is later checked against independent evidence?

Keep separate:

- spontaneous recall from prompt-evoked construction;
- remembered observation from interpretation or inference;
- episodic content from stable person/place models;
- specific memory from routine or general knowledge;
- direct recall from plausible completion;
- confidence from verified accuracy;
- internal reconstruction from new source access;
- recovery availability from knowing when recovery is needed.

Whenever possible, freeze a recall state before checking an external source.
