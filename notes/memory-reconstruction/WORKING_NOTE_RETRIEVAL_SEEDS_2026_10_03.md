# Working note — retrieval seeds / entry representations

**Date:** 2026-10-03  
**Status:** OBSERVATION / HYPOTHESIS — exploratory, not an established cognitive mechanism

## Pattern observed

Across several guided recall probes, a repeated pattern appeared: a place, episode, or salient event often became consciously available through one privileged visual starting state.

Observed examples:

- front of home → front-door / entry area;
- kitchen → first counter seen on entering;
- grocery trip → store entrance;
- leaving grocery store → cart / unloading transition;
- Tally robot event → the same initial visual of the robot from a familiar angle.

For Tally, the same starting representation appeared under at least two different cues:

- the direct cue **"Tally"**;
- the broader cue **"a recent moment when something surprised you."**

This suggests that the initial visual may function as more than a word association. It may be a stable access state for the event.

## Provisional term

**Retrieval seed** or **entry representation**:

> A compact, privileged representation that becomes active first and provides access to a larger place, episode, or event.

The seed need not contain the whole memory. It may instead act as a launch point from which richer structure can be reconstructed or navigated when a new demand is applied.

## Why "entry" may be broader than a literal entrance

Several place memories used literal entrances or transition points, but the Tally example suggests a more general structure.

The common feature may be closer to:

> the first stable frame at which the mind identifies "this is that thing / event."

For Tally, the privileged frame was tied to the significance of the encounter: the first time Vance noticed an intelligent inventory robot operating in a grocery store.

## Dynamic rather than purely static

The Tally retrieval was corrected from "snapshot" to a **specific moving visual fragment**: the robot moving from the familiar initial angle.

Therefore "retrieval seed" should not imply a still image. The seed may be a compact dynamic scene.

## Prompt contamination control

A methodological correction was observed during the same session.

When a question mentioned the shopper, Vance immediately jumped to the shopper scene. That should not be counted as spontaneous content in the initial Tally retrieval.

Future probes should therefore:

- avoid embedding candidate scene details in the question;
- use neutral cues;
- distinguish what appears before versus after elaborating prompts;
- treat prompt-induced expansion as a separate stage.

## Relation to Representation Science

This pattern is relevant to the distinction among:

- active representation;
- navigable retained structure;
- reconstruction;
- salience;
- query/demand state.

A possible architecture is:

cue or demand → retrieval seed → local reconstruction / navigation → richer scene

This is only a behavioral description of one participant's introspective report. It does not establish how biological memory is physically stored.

## Testable questions

1. Does the same event reliably return the same retrieval seed across days?
2. Can different cues converge on the same seed?
3. Do more salient events have more stable seeds?
4. Are seeds more often tied to boundaries, first recognition, novelty, or decision points?
5. Does the seed remain stable after later retelling or new information?
6. Can a seed be externally verified against photos, video, messages or other records?
7. Does targeted access to a local scene bypass the episode-level default seed without replaying the intervening sequence?

## Boundary

This note records a repeated exploratory pattern from one guided session. It does not establish a universal memory law, a neurological storage mechanism, or a claim that all episodic memory uses retrieval seeds.
